# Content rating questionnaire — the answers

Play uses IARC. Every question below is asked for the **Game** category.

| question | answer |
|---|---|
| Violence — does the game contain violence? | **No** |
| Does the game depict blood, gore, or injury? | **No** |
| Sexuality | **No** |
| Language | **No** |
| Controlled substances — drugs, alcohol, tobacco | **No** |
| Gambling — simulated or real | **No** |
| Does the app share the user's location? | **No** |
| Does the app allow users to interact or exchange content? | **No** |
| Does the app allow purchases? | **No** |
| Does the app contain ads? | **No** |
| Miscellaneous — does the app include user-generated content? | **No** |

Expected outcome: **PEGI 3 / ESRB Everyone / USK 0**.

One thing worth knowing before you answer: the game's failure state is called a
meltdown, and it empties the reactor. There is no depiction of harm to anyone,
no imagery of a disaster, and no casualty of any kind — a screen flash and an
empty grid. It is not a violence answer.
